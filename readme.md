A Minecraft Music Discs Player.

a website that Minecraft themed with the Minecraft Font and background, 
even to the play/pause buttons to actually play ingame findable discs,
I made this project as a learning/hobby project, I haven't touched 
Javascript before this website and web devolopment in general,
I find it a blast to make your own hobby project that you have a deep connection with
like me with Minecraft which of course if not obvious already is my favorite game of all time.

Web Functions:
A Static Background Image
A Bordered Section Previewing the current track playing
and the duration of it, 
three buttons a previous track, next track, and a play/pause button,
a slider to either go back in the track your currently listening to or forward.

A total of 23 songs from ingame collectible discs
